# 🎵 Composer

> A simple yet powerful notes app built with **Kotlin** and **Jetpack Compose** — designed to be minimal, local, and fast.

---

## ✨ Overview

**Composer** helps you jot down ideas, organize them with tags, and group notes for better focus.  
Everything stays **local**, lightweight, and private — perfect for everyday note-taking or idea sketching.

---

## 🧱 Features

- 📝 **Create, Edit, Delete Notes** — effortless local CRUD operations
- 🏷️ **Tags & Groups** — organize notes your way
- 🔍 **Search & Filter** — find notes instantly
- 🌙 **Material 3 + Compose** — clean, modern UI
- 💾 **Offline Storage** — data persists locally using Room
- 🎤 *(Coming soon)* **Speech-to-Text** — take notes by talking
- 🔄 *(Future idea)* Sync with your Flutter version for cross-platform access

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|----------|
| UI | Jetpack Compose (Material 3) |
| Architecture | MVVM + ViewModel + Repository |
| Storage | Room Database |
| DI | Hilt |
| Language | Kotlin |
| Build System | Gradle (AGP 8+) |
